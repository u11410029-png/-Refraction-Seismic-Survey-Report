## 3. 核心物理原理與公式推導

折射震測的基本物理機制與光學中的折射完全相同，均遵循**司乃耳定律（Snell's Law）**。詳細推導可參見本專案 [臨界折射波公式推導.PDF](file:///c:/Users/User/Downloads/2626-1007_北市大實習/2626-1007_北市大實習/臨界折射波公式推導.PDF) 與 [陳達毅教授期刊論文](file:///c:/Users/User/Downloads/2626-1007_北市大實習/2626-1007_北市大實習/04、教學現場〈淺層地底構造探勘：用「光的折射」原理透視地下世界〉陳達毅%2029_6076.pdf)。

### 3.1 司乃耳定律與臨界角

當震波由上層介質（波速 $V_1$）傳入下層較緻密高速介質（波速 $V_2$ 且 $V_2 > V_1$）時：

$$\frac{\sin\theta_1}{V_1} = \frac{\sin\theta_2}{V_2}$$

當入射角增大至某一特定角度 $\theta_c$ 時，折射角 $\theta_2 = 90^\circ$。此時折射波不再向下穿透，而是沿著兩層介質的交界面以高速 $V_2$ 滑行傳播，此角度稱為**臨界角（Critical Angle, $\theta_c$）**：

$$\sin\theta_c = \frac{V_1}{V_2}, \quad \cos\theta_c = \sqrt{1 - \left(\frac{V_1}{V_2}\right)^2} = \frac{\sqrt{V_2^2 - V_1^2}}{V_2}$$

依據**惠更斯原理（Huygens' Principle）**，高速滑行的波前在界面上每一點均會化為新的次級波源，以臨界角 $\theta_c$ 不斷向上折射返回地表，被地表的受波器接收，稱為**首波（Head Wave）**或**臨界折射波**。

### 3.2 雙層水平介質走時曲線（Travel-Time Curves）

假設地表覆蓋層厚度為 $h$，地表震源 $S$ 到受波器 $R$ 的水平支距為 $x$：

#### (1) 直達波（Direct Wave）
震波直接沿地表表層傳播，路徑長度為 $x$：

$$T_{\text{direct}} = \frac{x}{V_1}$$

- 在走時曲線圖（$t-x$ 圖）上為一條通過原點 $(0,0)$ 的直線，**斜率為 $\frac{1}{V_1}$**。

#### (2) 臨界折射波（Refracted Wave / Head Wave）
震波經歷三段路徑：以 $\theta_c$ 斜向下穿透至界面（路徑長 $\frac{h}{\cos\theta_c}$）、沿界面滑行（長度 $x - 2h\tan\theta_c$）、再以 $\theta_c$ 斜向上折射回地表（長度 $\frac{h}{\cos\theta_c}$）：

$$T_{\text{refr}} = \frac{2h}{V_1\cos\theta_c} + \frac{x - 2h\tan\theta_c}{V_2}$$

經代數化簡整理後，得到著名的**折射波走時方程式**：

$$T_{\text{refr}} = \frac{x}{V_2} + \frac{2h\sqrt{V_2^2 - V_1^2}}{V_1 V_2} = \frac{x}{V_2} + T_i$$

- 斜率為 $\frac{1}{V_2}$（由於 $V_2 > V_1$，折射波線段斜率比直達波更平緩）。
- 時間軸截距為**截距時間（Intercept Time, $T_i$）**：

$$T_i = \frac{2h\sqrt{V_2^2 - V_1^2}}{V_1 V_2}$$

### 3.3 超越距離（Crossover Distance, $X_c$）與地層深度推導

在近距離時，直達波路徑最短，最先抵達；隨著支距增大，雖然折射波繞了遠路，但其在深層高速滑行（如同走「高速公路」），會在某一特定距離處與直達波**同時抵達**。此交會點稱為**超越距離（$X_c$ 或 $X_{\text{cross}}$）**。

令 $T_{\text{direct}} = T_{\text{refr}}$：

$$\frac{X_c}{V_1} = \frac{X_c}{V_2} + \frac{2h\sqrt{V_2^2 - V_1^2}}{V_1 V_2}$$

$$X_c \left(\frac{1}{V_1} - \frac{1}{V_2}\right) = \frac{2h\sqrt{(V_2 + V_1)(V_2 - V_1)}}{V_1 V_2}$$

$$X_c \left(\frac{V_2 - V_1}{V_1 V_2}\right) = \frac{2h\sqrt{(V_2 + V_1)(V_2 - V_1)}}{V_1 V_2}$$

$$X_c (V_2 - V_1) = 2h \sqrt{(V_2 + V_1)(V_2 - V_1)}$$

解出覆蓋層厚度 $h$：

$$h = \frac{X_c}{2} \frac{\sqrt{V_2 - V_1}}{\sqrt{V_2 + V_1}} = \frac{X_c}{2} \sqrt{\frac{V_2 - V_1}{V_2 + V_1}}$$

此即著名的**超越距離求層厚公式**。

## 4. 實測數據分析與速度模型計算

### 4.1 野外人工判讀與經典計算（學生實習分析）

詳見手寫成果檔 [實際測量數據.PDF](file:///c:/Users/User/Downloads/2626-1007_北市大實習/2626-1007_北市大實習/實際測量數據.PDF)。

- **選用記錄**：Shot 109（第 9 炮，炮點位置 $x = 32$ m，震源位於第 17 道處，偏移量 $0$ m）。
- **人工波形挑選特徵**（波形圖第 1 頁）：
  - 敲擊點：第 17 道（$x = 32$ m，支距 $0$ m）。
  - 直達波到達曲線：由 0 m 向兩側延伸，在支距 $x = 15$ m（第 9 道）處，到時 $t = 0.046$ s。
  - 臨界折射波到達曲線：在遠支距 $x = 32$ m（第 1 道）處，到時 $t = 0.052$ s。
  - **超越距離判定**：$X_c = 15$ m，交會到時 $t_c = 0.046$ s。
- **數值代入與計算**（計算筆記第 2 頁）：
  1. **表層波速 $V_1$**：
     $$V_1 = \frac{X_c}{t_c} = \frac{15\text{ m}}{0.046\text{ s}} \approx 326\text{ m/s}$$
  2. **下層高速層波速 $V_2$**：
     $$V_2 = \frac{\Delta x}{\Delta t} = \frac{32 - 15}{0.052 - 0.046} = \frac{17\text{ m}}{0.006\text{ s}} \approx 2833\text{ m/s}$$
  3. **表層地層厚度 $h$**：
     $$h = \frac{X_c}{2} \sqrt{\frac{V_2 - V_1}{V_2 + V_1}} = \frac{15}{2} \sqrt{\frac{2833 - 326}{2833 + 326}} = 7.5 \times \sqrt{\frac{2507}{3159}} \approx 7.5 \times 0.8908 \approx 6.68\text{ m}$$

> **地質意義詮釋**：
> - $V_1 \approx 326$ m/s 吻合校園地表未固結之鬆散表土、填土層特性（波速一般在 300–400 m/s）。
> - $V_2 \approx 2833$ m/s 呈現堅硬緻密未風化之沉積岩基盤或飽和含水深層結構特徵。
> - 表層厚度約 6.7 公尺，揭示了圖書館後方風化表土覆蓋層的真實厚度。

### 4.3 關鍵科學發現：為什麼自動程式難以取得 V₁？

在進行全自動初達波反演時，若將視速度搜尋視窗下限由 160 掃描至 300 m/s，可得到以下驚人的穩定度檢驗結果（詳見 `web/sensitivity.csv`）：

| **2 m** | 286 | 320 | 333 | 348 | 381 | 533 | 變動 67% | **極不穩定（偽訊號）** |

| **8 m** | 547 | 547 | 547 | 533 | 547 | 557 | **變動僅 4%** | **極穩定（真實地層）** |
| **10 m** | 533 | 533 | 533 | 556 | 556 | 556 | **變動僅 4%** | **極穩定（真實地層）** |
| **12 m** | 578 | 578 | 589 | 589 | 589 | 589 | **變動僅 2%** | **極穩定（真實地層）** |
| **14 m** | 569 | 571 | 571 | 593 | 602 | 619 | **變動 9%** | **穩定（真實地層）** |
| **16 m** | 587 | 587 | 587 | 634 | 634 | 688 | 變動 16% | 開始受 SNR 衰減影響 |

> **核心結論：**
> 1. **近支距（$<8$ m）的視速度完全隨程式參數漂移**：這是因為近地表產生了能量極強的**表面波（地滾波 Ground Roll，速度僅約 127–160 m/s）**，自動演算法在極短時間內難以區分微弱的直達 P 波初達波與強烈表面波。
> 2. **中支距（8–14 m）視速度 533–578 m/s 極其穩定**，代表穩定的折射層傳播。
> 3. 這正是為什麼**人工判讀（Manual Picking）不可取代**：學生透過眼睛與物理直覺，能夠在近支距清晰辨識出微弱但最先跳動的直達波，從而成功解算出第一層真實波速 $V_1$（如 326 m/s）。

## 5. 原始觀測資料格式與解析指引

### 5.1 SEG-2 原始檔案（Geometrics DAS-1）

存放於 `seg2/101.dat` ～ `112.dat`，共 12 個檔案。

- **檔案標頭（File Header）**：
  - 前 32 bytes 包含 Magic Number `0x3A55`（ASCII `U:`）及子標頭計數。
  - 包含 10 筆文字子標頭：`ACQUISITION_DATE`、`ACQUISITION_TIME`、`INSTRUMENT`、`UNITS METERS` 等。
- **Trace 結構**：
  - 每檔固定包含 24 道，每道 stride 約 8,480 或 8,484 bytes。
  - 二進位 Trace Header（32 bytes）：包含資料偏移量（480 或 484 bytes）、樣本數（2,000）、位元組數（8,000）。
  - 文字子標頭：記錄 `CHANNEL_NUMBER`、`DELAY`、`DESCALING_FACTOR`、`SAMPLE_INTERVAL 0.00025`、`STACK` 等。
  - **資料本體**：2,000 個 **Little-Endian 32-bit IEEE 浮點數**（8,000 bytes）。

### 5.2 SEG-Y 彙整檔（288 道）

檔案為 `202610_UTELS.sgy`，大小為 2,376,720 bytes。

- **檔案組成**：
  $$\text{大小} = 3200 \text{ bytes (EBCDIC/ASCII 標頭)} + 400 \text{ bytes (二進位標頭)} + 288 \times 8240 \text{ bytes (Trace)}$$
- **二進位標頭（Binary Header）**：
  - 取樣間隔：$250\ \mu\text{s}$（0.25 ms）。
  - 每道樣本數：2,000。
  - 資料格式碼（Format Code）：**1**，代表 **4-byte Big-Endian IBM 浮點數**。
- **Trace 標頭關鍵欄位**：
  - `fldr`（偏移 8）：炮號 101 ～ 112。
  - `tracf`（偏移 12）：道號 1 ～ 24。
  - `cdp`（偏移 20）：CMP 坐標 $(x_{\text{src}} + x_{\text{rcv}})/2$。
  - `rx`（偏移 36）：相對偏移支距（Receiver Offset, $-44 \sim +46$ m）。
- **Trace Balancing（振幅正規化注意）**：
  - SEG-Y 的每一道均經過單道平均絕對振幅正規化（$\text{mean}(|sgy|) = 100$）。
  - 若需精確振幅分析（如真振幅衰減），請回到原始 SEG-2 檔並乘以 `DESCALING_FACTOR`。

### 5.3 幾何資訊陷阱與注意事項

> [!WARNING]
> 1. **SEG-2 檔頭幾何為儀器預設模板**：原始 `101.dat`–`112.dat` 檔頭內的 `SOURCE_LOCATION` 每檔均固定為 `4.00`，`RECEIVER_LOCATION` 固定為 `0.00–23.00`。這是當天儀器設定未手動變更導致的預設值，**切勿直接拿來計算座標**！
> 2. **真實幾何請參照 `202610_UTELS.geom` 或 `202610_UTELS.sgy` 標頭**：
>    - 受波器絕對位置：$0, 2, 4, \dots, 46$ m。
>    - 震源絕對位置：$4 \times (\text{炮號} - 101)$ m。

### 5.4 Python（ObsPy）資料讀取範例

```python
import numpy as np
from obspy import read

# 1. 讀取 SEG-2 原始單炮記錄（以 101.dat 為例）
st_seg2 = read("seg2/101.dat", format="SEG2")
print(f"SEG-2 檔案道數: {len(st_seg2)}")
tr = st_seg2[0]
print(f"第 1 道採樣率: {tr.stats.sampling_rate} Hz, 樣本數: {tr.stats.npts}")
print(f"第 1 道疊加次數: {tr.stats.seg2['STACK']}")

# 2. 讀取 SEG-Y 全測線彙整檔（288 道）
st_segy = read("202610_UTELS.sgy", format="SEGY")
print(f"SEG-Y 總道數: {len(st_segy)}")  # 288

# 3. 提取炮號、道號與正確支距
for tr in st_segy[:24]:
    shot_no = tr.stats.segy.trace_header.field_record_number  # 101~112
    trace_no = tr.stats.segy.trace_header.trace_number_within_field_record
    offset = tr.stats.segy.trace_header.x_coordinate_of_ensemble_member
    print(f"炮號: {shot_no}, 道號: {trace_no:02d}, 支距: {offset:+3d} m")
```

### 6.1 六步科學建模歷程與 CER 框架

本實習超越單純的操作教學，是一場嚴謹的科學建模探究：

```mermaid
graph LR
    A["1. 提出問題<br>(看不見的地下)"] --> B["2. 設計觀測<br>(震源與受波器)"]
    B --> C["3. 取得證據<br>(支距與走時)"]
    C --> D["4. 找出規律<br>(t-x 走時曲線)"]
    D --> E["5. 建立模型<br>(地下雙層速度)"]
    E --> F["6. 檢驗修正<br>(多震源互換驗證)"]
```

#### CER（主張-證據-推論）檢核點
- **主張（Claim）**：地下並非均質單一層，而是至少存在兩層物性截然不同的速度層。
- **證據（Evidence）**：走時曲線（$t-x$）呈現斜率明確轉折的兩段直線，遠距離初達波視速度明顯提升。
- **推論（Reasoning）**：走時圖斜率為波速倒數（$1/v$），斜率變緩代表深層波速較快，震波走臨界折射波路徑後來居上。
